# Review: Data Visualization Studio (mindframe) — round 0

**VERDICT: TWEAK**

The hovering hero (bar-chart skyline + line-graph ribbon + scatter-dots + legend) is genuinely strong and the form is a wide low gallery, not the gateway cube. But this is the **glass showpiece**, and the big windows fail the glass contract: the front face is a noisy diagonal scatter of black `K` pixels dissolving the glazing into static instead of reading as a few large, clean, sheen-lit panes. That is the automatic-TWEAK condition for this batch.

## Per-criterion

1. **Iso 2:1?** Pass. The roof ridge / eave lines and the right-face footing run at the correct 2:1 diagonal (rows 23→44). Geometry is sound.
2. **Roof visible?** Pass. The flat `M`/`L` gallery roof reads as a 3/4 top-down plane across rows 18–26 (the broad `L` light wash, cols 18–40), with the skylight lantern ridge and the hero projecting above it. Good roof presence.
3. **Front corner faces viewer?** Pass. The near vertical corner lands around col 30–33 (rows 27–44), splitting the lit-LEFT glass face from the shaded-RIGHT face. Reads correctly.
4. **Sharp/clean/in-palette/K outline/no strays — AND glass-reads-as-glass (CRITICAL):** **FAIL on the glass.** Palette is clean and in-set, the `K` perimeter outline is solid, and I see no off-palette/AA strays — the craft on edges is fine. BUT the lit-LEFT display windows do NOT read as glass. Source rows 27–37 show `K` pixels peppered *through the interior* of the panes in an irregular diagonal scatter — e.g. row 27 `KMKhKKMK`, row 29 `KMKgghhhKKMK`, row 33 `KMKKhhcGcggg`, row 37 `KMKggWWGW`. There is no clean mullion grid and no large unbroken pane; the glazing fragments into black-flecked noise (this is precisely the "flat panel chopped by black `K` bars" / black-segmented-glazing automatic-TWEAK). The painter's self-noted weak spots (highlighted bar, edge scatter-dots) are minor by comparison — the real problem is the windows.
5. **Cohesive MindFrame palette + motifs?** Pass. Indigo/violet walls (`M`/`D`/`d`), `o` magenta accent strip on the eave (visible cols ~16–17 rows 23–24 and the front lip row 47 `roOor`), soft data-screen glow on the hero. Motif vocabulary is on-brand. Loses points only because the "clean observation glass" motif — the building's whole identity — is the part that misfires.
6. **One-of-one signature present + legible + distinct?** **Pass, strong.** All four elements are present and read distinctly: (a) 3D bar skyline — a row of ~9 `c`/`h`/`o` iso bars at varying heights with `K` edges and `h` tops (rows 11–17); (b) line-graph ribbon — the `o`/`O` magenta ribbon arcs cleanly over the bars with node-dots (rows 5–11); (c) scatter-dots streaming in — the `c`/`g`/`h`/`o` dot column at col 39 drifting down toward the building (rows 18–23); (d) color legend — the `K`-framed swatch stack at cols 13–18 with `g`/`O`/`c` chips and `WW` label ticks (rows 11–17) reads instantly as a legend. No pie chart. Clearly distinct from Stat Hub's bell curve. This is the best part of the sprite.
7. **Attractive?** Partial. The hero composition above the building is beautiful and balanced. The building body, however, looks busy/glitchy because of the noisy glass — the eye reads static where it should read serene exhibition glass. Fixing #4 fixes this.
8. **Unique built form + opening on LIT-LEFT?** Pass on form (wide low glass-forward gallery, not a generic box, not the gateway cube). Opening/hero glazing is on the **LEFT** lit face as assigned. Form and orientation are correct.

## Tweak list (painter-actionable)

1. **Rebuild the LEFT display windows as 2 large clean glass panes, not a noise field.** In rows ~24–43, define exactly TWO big panes separated by ONE vertical `K`/`d` mullion (and a single horizontal sheen break is fine). Remove the scattered interior `K` pixels that currently fleck the glazing (the `KMK...K` runs in rows 27–37). Each pane should be a mostly-unbroken field of glass color.
2. **Use a real glass ramp inside each pane, top-lit.** Fill panes with a smooth `c`→`g`→`G` (or `L`→`M`→`D`) vertical gradient — lighter at the top, darker at the bottom — instead of the current salt-and-pepper of `g`/`h`/`c`/`L`/`K`. No black inside the pane body.
3. **Add a clean sheen streak.** Lay a 1–2px diagonal `W`/`h` highlight across each pane (top-left to lower-right) so the glass reads reflective. Keep it single, deliberate, and unbroken — one sheen per pane, not speckle.
4. **Give each pane a clean K frame, then leave the inside alone.** A 1px `K` (or `d`) frame around each pane edge is the only black allowed in the window; the interior stays glass.
5. **Let the chart-behind-glass be a faint hint, not literal noise.** If you keep "charts visible inside," make them a single subtle `o`/`h` ghost shape (e.g. one faint bar or line) low-contrast against the glass — don't try to render a full dashboard inside the pane; that's what's creating the static.
6. **(From painter's note) Color the tallest hero bar distinctly.** The highlighted/tallest bar in the skyline currently distinguishes mostly by height. Give it a brighter `g`/`G` or `O` face so it reads as the keyed/featured series (and ties to a legend chip).
7. **(From painter's note) Pull the two edge scatter-dots in from x62–63.** Move the dots off the canvas edge by 1–2px so they don't clip / sit flush to the frame; keep the scatter stream inside the safe area.
8. **(Optional) Sharpen the shaded-RIGHT face contrast.** It currently blends into the front; a touch more `D`/`d` darkening on the right plane (cols ~46–52) would strengthen the front-corner read — minor, do after the glass.
