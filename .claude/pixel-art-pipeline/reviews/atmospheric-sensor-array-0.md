# Review: Atmospheric Sensor Array (terrabase) — round 0
**VERDICT: TWEAK**

Strong, distinctive built form — a real cluster of staggered stacks with the opening correctly on the shaded RIGHT face. But the one-of-one signature does not land: the crown gas reads as EXHAUST/spray (not inhaling), the bell-jar analyzer is on the wrong (left) face, and there is no legible predicted-concentration needle/dial. The signature is the whole point, so this is a TWEAK.

## Per-criterion

1. **Iso 2:1?** PASS. The base box is a clean 2:1 iso prism; left and right wall faces fall at the correct diamond slope, deck diamond is correct.
2. **Base roof / deck visible 3/4 top-down?** PASS. The flat `L`/`M` deck top is clearly visible with the stacks standing on it; we see the top plane, not just walls.
3. **Front corner faces viewer?** PASS. The near vertical corner of the base points at the camera; lit-left / shaded-right faces split correctly off it.
4. **Sharp / clean / in-palette / clean K outline (round cylinder shading)?** MOSTLY PASS. Edges are crisp single-pixel, hard `K` outline present, cylinders carry left-lit→right-shaded banding. Colors look in-palette. Minor: a couple of near-white `h` pixels on the deck/left-base bell-jar blob verge on flat brightness, but acceptable.
5. **Cohesive TerraBase palette + motifs?** PASS. `M`/`D` weathered steel stacks, `o` hazard collars at intervals, mineral-teal `c`/`g` sensor glow, ochre/slate base. Weatherproof-instrument tank-farm motif is on-brand.
6. **One-of-one signature present + legible + distinct?** FAIL (the deciding issue). Three sub-problems:
   - **Gas reads as EXHAUST, not INTAKE.** The crown wisps (top ~rows 0–110) are thin `c`/`o` arcs that fan OUTWARD and UPWARD away from the horn mouths. There is no curl-DOWN-into-the-mouth, no offset "being sucked in" gesture. Combined with the bright teal vertical stripe running down the tall stack, the whole crown reads like a fountain/emission. This is exactly the painter's self-noted weak spot, and it is the dominant failure.
   - **Bell-jar analyzer is on the WRONG face.** The glowing `c`/`h` bell-jar blob sits on the LEFT base face / front-left deck edge, not inside the right-side bay. The right bay has a lit `K`-framed window (good glow on the shaded side) but no legible jar+dome inside — it reads as a generic lit window, so the hero is split and half of it is on the lit-left.
   - **Predicted-concentration needle/dial not legible.** The bright teal vertical stripe down the tall stack reads as a sight-strip/gauge ribbon, not a needle climbing a dial. No `K`-framed dial with `o`/`O` needle and a bright `O` forecast-threshold mark is readable anywhere.
   - Minor: horn mouths are tiny dark `K` caps — they read as plain stack caps, not flared upward funnels.
7. **Attractive?** PASS. Pleasing silhouette, good height variation, nice teal accents; it's a handsome sprite — it just tells the wrong story.
8. **Unique built form + opening on assigned RIGHT + glowing on shaded side?** PASS on form and opening. Genuine cluster/tank-farm of 4–5 staggered cylinders — not the gateway cube, not a single column, distinct from every TerraBase sibling. Opening is on the RIGHT and the bay glows on the shaded right face. (The bell-jar being duplicated/placed on the LEFT undercuts the "glow belongs to the right bay" read — see tweak 3.)

## Numbered, painter-actionable tweak list

1. **Flip the gas from exhaust to INTAKE (highest priority).** Crown region above the stacks (roughly rows 0–110, cols spanning the horn tops). Redraw the `c`/`o`/`g` wisps as short comma-shaped curls whose tails start OUT in the air (1–2px `o`/`O` and `c` dabs offset up-and-away) and whose heads bend DOWN and INWARD into each horn mouth. Add a faint 1px `K`/`G` "swallow" shadow just under each mouth so the wisp visibly disappears into the horn. Remove the tall upward fountain arcs — keep wisps low, dense near the mouths, sparse above. Goal: the eye reads air being inhaled, not sprayed out.
2. **Make the horn mouths read as flared funnels.** On each stack top, widen the cap by 1px on the lit-left and add a 2px `D`/`M` flare with a faint `K` inner rim (a dark mouth hole), so each horn reads as an upward sniffer-funnel rather than a flat `K` cap. The tallest stack's horn should be the most legible.
3. **Move the bell-jar analyzer INTO the right bay and remove the left-face duplicate.** Delete the glowing `c`/`h` bell-jar blob currently on the LEFT base face / front-left deck. Inside the existing `K`-framed right-bay window, paint a small `c`/`h` glass bell-jar dome (rounded top, 2px tall highlight `h` on the lit edge) over a glowing `g`/`G` analyte puck, with an `o`/`c` swirl tint inside to show collected gas. The lit-left base face should stay plain — one `c` ribbon window + a vent only.
4. **Add a legible predicted-concentration needle + dial in/beside the right bay.** Beside the bell-jar in the right bay, add a tiny `K`-framed dial: an `o`/`O` needle angled UP toward a bright single `O` pixel = the forecast-threshold mark, plus a 1–2px `g` ppm tick readout below it. This is the "prediction" beat and is currently missing.
5. **Demote the tall-stack teal stripe.** The bright full-height teal stripe on the tallest stack reads as a fountain/gauge and competes with the new dial. Either narrow it to a 1px `c` sight-strip (per blueprint) or break it into short `c` segments so it reads as a sensor sight-line, not a flowing column of liquid/gas.
6. **Thin `D` sample-lines tying horns to the analyzer.** Optional but helps the "funneling down into the analyzer" story: run 1px `D` sample-lines from a couple of horn collars down the shaded side toward the right-bay analyzer, so the path from intake to bell-jar is visible.
