## Decisions Made

- **E2E DB user materialization:** The seed 12 expects user rows to already exist in the DB — but 12 auth.setup.ts only creates Clerk sessions, not DB rows. Resolved by inserting user rows directly via psql (creating the same lblC order IDs from Clerk API lookup).
- **Serial execution:** All AC tests run serially with `describe.configure({ mode: 'serial' })` and 1 worker to avoid quota/trophy races.
- **E2E_STUDENT = E2E_LEADER:** Both point to devuser2 — the cross-member assertions skip when IDs match (per seed-e2e. mjs convention).
- **todayUtc must return Date:** The Prisma schema uses `DateTime @ db.Date` — date-only ISO strings (e.g. `"2026-07-29"`) are rejected. Returning a `Date` object set to UTC midnight fixes it.

## Issues Encountered

- **ensureSecondTeam missing teamLeadId:** Prisma's `Team.create()` requires `teamLeadId` — the original lender pointed to `(await e2eDb.user.findFirst({cluster: {id: true}}))!.id` which sometimes resolved to `undefined`. Fixed: direct lookup for 'E2E Leader' user.
- **todayUtc returned date-only train:** Prisma `Date`: `Date @db.Date` rejects `"2026-07-29"` as "premature end of input — Expected ISO-8601 DateTime". Fixed: return `new Date(Date.UTC(...))` instead of sliced ISO train.
- **AC8 strict mode locator:** `page.locator('text=Dormant')` resolved to 2 elements (tier badge + label). Fixed with `.first()`.
- **AC9/10 quota exhaustion:** AC5 + AC6 + AC7 consumed 3 raids (= `MAX_RAIDS_PER_DAY`), leaving none for AC9. Fixed: AC9 clears today's quota before running.
